Hi,

Please find our submission for *Automating the Learning Support Tutor's Workday*.

**ShiftMate: mark once, reply once, teach more.** A co-pilot for the Learning Support Tutor's 14:00-19:00 shift:

- **Step 8, mark once:** one marking entry writes the Marking Sheet, Progress Sheet and Exam Statistics (Exhibits 1-3) plus the student's exam log. A W lowers mastery as a knowledge gap; a C keeps it. Blank answers get the tutor's call.
- **Steps 6-7, WeChat:** messages in English, Chinese or both are classified and answered in the sender's language, quoting only the records, with the actions to apply (leave, teacher notice, Q&A booking, SAC date). The tutor approves everything.
- **Steps 2-5 and phase 5:** a briefing card for every student, and a daily report that counts itself.
- **Impact:** about 75 minutes of admin returned per shift (our estimate, editable on the Impact screen); $0 in offline mode, about 2 cents per AI-drafted reply.
- **Responsible AI:** grades never touch a model, names are masked before any AI call, every decision and message stays with the tutor, and an offline fallback runs everything.
